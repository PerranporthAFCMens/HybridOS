# Workout builder in the new app (9 October 2026)

**Branch `rebuild-workouts`. New `/next/` app only; same tables as the old Workout builder page (`workout_templates`, `workout_template_blocks`, `workout_template_activities`, `workout_assignments`, `workout_wods`); no database changes. Status: on a branch (PR open). Changes `web/package.json`, the layout audit and the shell menu, so the owner merges.**

New `/next/#/workouts` (a "Workout builder" item in the sidebar and a button on Classes): the workout library; open or create a workout (name, type, focus tags, minutes, description, who can see it); blocks (name, format, rounds, instructions) each with activities (exercise, what to track, prescription, coach notes); move blocks and activities up and down; **Assign to member** (a personal training assignment: the member gets a copy of the workout as it is now, with an optional due date at the end of that day in UK time); **Publish as WOD** (the gym workout of the day for a chosen date, replacing an earlier one for the same day); **Archive** (asks first; it leaves the library and members who already have it keep their copy).

**Safer than the old page:**
- The old save deleted every block and then re-added them, so a failure half-way left a workout empty. The new save writes the new blocks and activities first and removes the old ones last.
- Rounds on a block, and anything else stored with an activity's prescription, were silently dropped on every save; they are now kept.
- Assign and Publish are only available when the workout is saved with no unsaved changes, so a member never gets a version you did not intend.
- Limits are checked before saving (name, minutes 1 to 600, up to 12 focus tags, description length, rounds).

**Known limits:**
- The database only lets the person who last saved a workout change it (it records them as the creator), so saving a workout made by someone else makes you its creator. This is the same as the old page.
- Personal training appointments (`pt_appointments`) are still saved with no scheduling checks and are not part of this piece; they need a checked database function (exact SQL for the owner's approval).
- Staff and coaches use the staff app, not this screen (the new admin app is for owners and admins).
