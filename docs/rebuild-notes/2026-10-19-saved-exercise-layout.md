# Saved exercise layout (new member app)

- Once an exercise is saved on the workout screen, its sets are listed one per line and numbered, instead of one long run-on sentence.
- Change and Remove sit side by side under the list.
- Wording of each set is unchanged (`setText`); only the layout changed. No database change.
- Files: `web/src/train/Player.tsx`, `web/src/member/member.css`, `web/browser/train.mjs` (checks the three saved sets show as three numbered lines).
