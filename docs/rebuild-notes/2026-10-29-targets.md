# Targets: monthly goals for the gym and for each coach

Gym touched: all gyms (new per-gym table). Puffin Performance is the test gym; Hybrid Hub has no rows until an owner sets one.

## What changed
- New table `gym_targets` (migration `20261029100000_gym_targets.sql`, undo `supabase/rollback/20261029_drop_gym_targets.sql`). **Adam runs the SQL by hand**; merging does not apply it.
- Gym goals: income collected (pounds a month), new members a month, active members.
- Coach goals: classes taught a month, PT sessions done a month.
- A goal repeats every month until changed. Empty box = no goal.
- Owners and admins read and change all goals. A coach or staff member can read their own only (the screen for coaches comes later). Members cannot see the table.
- New report "Targets" (in the "Your own" group): progress this month with a bar per goal, and a box to set each goal.
- The Reports summary shows a "Goals this month" box when gym goals are set. If the table does not exist yet, the summary just has no goals box (nothing breaks).

## Not done here

- Alerts when a goal is missed.
